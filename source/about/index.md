我是小舟。这里放技术笔记——密码学、逆向、前端工程，以及那些调了三小时才发现的边界情况。

写下来的理由很实际：下次遇到同样的问题，能直接抄自己的作业。

## 这里有什么

- **原理拆解**：把协议或算法摊开讲清楚，而不是贴个结论
- **踩坑记录**：报错原文 + 根因 + 最终的解法
- **CTF 复盘**：题目思路和能跑的脚本

## 关于这个站

用 [Hexo](https://hexo.io/) + [Butterfly](https://butterfly.js.org/) 搭建，托管在 GitHub Pages。

没有数据库、没有追踪脚本、没有广告，整个站就是一叠静态文件。
